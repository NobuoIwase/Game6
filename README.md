# EARTH DEFENSE TEST（地球防衛軍ライク TPS・テスト版）

「地球防衛軍」シリーズを参考にした三人称視点シューティングの**テストゲーム**です。
現代の市街地に現れた巨大生物と侵略兵器を、陸戦兵がアサルトライフルとミサイルランチャーで迎え撃ちます。
ブラウザで動くので、**PC とスマートフォンの両方**で遊べます（スマホはタッチ操作）。

> 個人制作のファンメイド作品です。ゲーム内の名称・データはすべてオリジナル（AF-T1 など）です。

## 遊び方

必要なもの: [Node.js](https://nodejs.org/) 20 以上（動作確認は 22）

```bash
npm install        # 初回のみ
npm run dev        # 開発サーバー起動 → http://localhost:5173 をブラウザで開く
```

- スマートフォンで遊ぶ: PC と同じ Wi-Fi に接続し、`npm run dev` の表示にある `Network:` の URL をスマホのブラウザで開きます（`--host` 指定済み）。
- 配布用にビルド: `npm run build` → `dist/` フォルダを任意の静的サーバー（GitHub Pages など）に置くだけで動きます（相対パスでビルドしています）。ビルド結果の確認は `npm run preview`。
- 型チェックだけ行う: `npm run typecheck`

タイトル画面で **武器1・武器2・難易度・画質** を選び「出撃」。全ウェーブの敵を全滅させるとミッションクリアです。

## 操作方法

| 操作 | PC | スマートフォン |
|---|---|---|
| 移動 | W A S D | 画面左側をドラッグ（仮想スティック） |
| 視点 | マウス（画面クリックでマウスを固定） | 画面右側をドラッグ |
| 射撃 | 左クリック（押しっぱなしで連射） | 「射撃」長押し（押したままドラッグで照準） |
| ズーム | 右クリック（押している間） | 「ズーム」（切り替え） |
| リロード | R | 「リロード」 |
| 武器切替 | Q / E / ホイール / 1・2 | 「武器切替」 |
| ジャンプ | Space | 「ジャンプ」 |
| 緊急回避（前転） | Shift（または C） | 「回避」 |
| ポーズ | Esc / P | 「Ⅱ」 |

- **ミサイルランチャー**は構えているだけで、画面中央付近（点線の枠）の敵を自動でロックオンします（最大4体）。射撃で一斉発射し、ミサイルが目標を追います。
- 残弾が 0 になると自動でリロードします。
- 自分の爆発（ミサイル・ロケット）に巻き込まれるとダメージを受け、吹き飛びます。

## 技術構成（エンジン選定の理由）

| 項目 | 採用 | 理由 |
|---|---|---|
| ゲームエンジン | [Babylon.js](https://www.babylonjs.com/) 9.30 | 無料・オープンソース（Apache-2.0）。WebGL2 で PC・スマホのブラウザ両方で動き、インストール不要で配布できる。PBR・影・ポストエフェクト・パーティクルが標準装備 |
| 物理エンジン | [Havok Physics for Web](https://www.npmjs.com/package/@babylonjs/havok) 1.3 | Babylon.js 公式の物理エンジンで MIT ライセンス・商用無料。関節（6DoF 制約）でラグドールを作れる |
| 言語・ビルド | TypeScript + [Vite](https://vite.dev/) | 型で安全に拡張でき、他の開発者・AI が読みやすい |
| 効果音 | WebAudio で合成 | 外部音声素材なし（ライセンス問題なし・軽量）|
| 素材 | [Poly Haven](https://polyhaven.com/) CC0 テクスチャ・HDRI | 実写ベースでリアル。パブリックドメイン相当 |

キャラクターや敵のモデルは外部素材を使わず、コードで部品を組み立てています（後で glTF モデルに差し替え可能。[引き継ぎ資料](docs/HANDOFF.md)参照）。

## カスタマイズ方法

### 武器を追加・変更する
`src/data/weapons.ts` の `WEAPONS` 配列に1件追加するだけです。出撃前画面のリストにも自動で並びます。

```ts
{
  id: "af_t2", name: "AF-T2 アサルトライフル", category: "アサルトライフル",
  kind: "hitscan",      // hitscan=即着弾 / rocket=直進弾頭 / homing=誘導ミサイル
  model: "rifle",       // 見た目: rifle / shotgun / sniper / launcher
  damage: 22, pellets: 1, fireRate: 15, magazine: 200, reloadTime: 1.8,
  spread: 1.2, range: 260, zoom: 1.6, speed: 650, blastRadius: 0, knockback: 2,
  buildingDamage: 0.6, recoil: 0.004, automatic: true, sound: "rifle",
  desc: "説明文",
},
```
初期装備は `DEFAULT_LOADOUT` で変更できます。新しい射撃方式（例: 火炎放射）は `WeaponKind` を増やし、`src/combat/Weapon.ts` の `fire()` に分岐を追加します。

### 敵の強さを調整する
`src/data/enemies.ts`（体力・速度・索敵距離・連鎖範囲・攻撃間隔など）。難易度倍率は `src/data/missions.ts` の `DIFFICULTIES`。

### ミッションを作る
`src/data/missions.ts` の `MISSIONS` にウェーブを並べます。発生条件は `start`（開始時）・`remaining`（残り敵数）・`time`（経過秒）。`active: true` のグループは出現と同時に襲ってきます（増援）。

## 設計メモ（地球防衛軍らしさの再現）

- **敵の待機とアクティブ化**: ファンが運営する攻略 wiki（[EDF5：地球防衛軍5@Wiki](https://w.atwiki.jp/edf5/) など）の検索結果では、敵は「動き回るだけで攻撃してこない待機状態（ノンアクティブ）」と「向かってくる攻撃状態（アクティブ）」を持ち、攻撃を受けた敵や周囲の敵は連鎖的に反応すると説明されていました（作品・敵の種類で細部は異なります）。本作では
  - 待機中: 巣の周りをうろつく（蟻）／その場で小さく跳ねる（蜘蛛）／上空を周回（飛行型）
  - 起動条件: 被弾、またはプレイヤーが索敵距離（`detectRange`）に入る
  - 連鎖: 起動した個体の「同じ群れ」と「`alertRadius` 内の敵」が、距離に応じた時間差で次々に起動
  としています（`EnemyManager.alert`）。少しずつ敵を「釣る」立ち回りが可能です。
- **蟻型**: 左右に散開して包囲しながら接近。中距離で腹部を曲げて酸を放物線状に一斉噴射。至近距離は噛みつき。ビルの壁をよじ登って最短距離で迫る。
- **蜘蛛型**: 跳躍で間合いを詰めたり回り込んだりし、好みの距離を保つ。扇状の糸が当たると「拘束値」がたまり、100 で糸に絡まって倒れる（ラグドール）。
- **飛行型**（イメージ画像の下半分）: 隊長機が経路を決め、僚機は V 字・横一列・くさび形の編隊位置を保つ。旋回時は大きくバンクし、急旋回ではほぼ裏返る。最初の 2 航過は機銃掃射、その後は絨毯爆撃の航過が交互に来る。
- **ラグドール**: `src/core/Physics.ts` の `Ragdoll` は「関節位置を原点にしたパーツの木構造」から剛体と 6DoF 関節を自動生成する汎用クラス。兵士・蟻・蜘蛛すべて同じ仕組み。飛行型は関節なしでバラバラに飛び散る。
- **建物の倒壊**: 建物ごとに体積に応じた耐久値。0 になると揺れながら沈み、土煙と破片（物理演算）を出し、がれきが残る。

## 既知の問題・今後の予定

- [ ] キャラクター・敵モデルはコードで組んだ簡易形状。リアル調を突き詰めるなら glTF モデル（スキンメッシュ）への差し替えが必要
- [ ] 味方 NPC 部隊（隊長・隊員）が未実装
- [ ] 敵の経路探索は直線移動＋壁登りのみ（飛行型は建物の上を飛び越える）
- [ ] 車はプレイヤー・敵との当たり判定なし（爆風で吹き飛ぶのみ）
- [ ] JS バンドルが約 7MB（gzip 1.5MB）。`@babylonjs/core` を個別インポートにすれば大きく削減可能
- [ ] 効果音は合成音。録音素材に差し替える余地あり
- [ ] スマホの実機での性能は未計測（開発環境では CPU レンダリングでの動作のみ確認）
- [ ] 武器のアンロックやミッション選択などのメタ要素は未実装
