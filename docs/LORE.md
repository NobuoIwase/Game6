# 世界設定（アンカー）

依頼者から提示された設定をまとめたもの。ゲーム内の名称・演出・今後の敵追加はこの設定に合わせる。
（用語の表記は依頼者の原文どおり。解釈が必要な箇所は「※」で注記）

## アンカーとは

- 作中の敵はすべて「**アンカー**」と呼ばれる。
- 名前の由来: 上空から落下してきた**槍型の物体が地面に突き刺さり**、そこから**分裂して巨大生物が発生した**ため。
- すべて**生物**。円盤や杭のような人工物に見えるものも含めて生き物である。

## 飛来の経緯

1. 太陽系外から**亜光速**で飛来した。
2. 地球の**重力を検知した時点で自動的に減速**し、重力にキャッチされた。
3. 地球の重力圏内（**月よりも外**）の衛星軌道上に、超超巨大型の円盤「**大陸級**」が停泊している。
4. 大陸級から放たれたのが「**国家級**」（杭）。重力方向（惑星）に対して自分たちの生命を広げるため、アンカーを打ち込んだ。
5. 最初の着弾は**アメリカ（ニューヨーク）**。そこから**地球の自転に合わせて西側へ**順にアンカーを落としていった。

## 階級（大きい順）

| 階級 | 説明 |
| --- | --- |
| 大陸級 | 衛星軌道上（月より外）に停泊する超超巨大型の円盤 |
| 国家級（杭） | 大陸級から放たれる。全長 約10km、芯は直径 約1km、かえしのような棘を含めると直径 約2km |
| 母艦級 | 国家級のトゲトゲ部分が分裂して飛び立ったもの。直径 約500m の巨大円盤 |
| 戦艦級（スポーンシップ） | 同じく国家級のトゲトゲ部分から分裂して飛び立ったもの |
| 巨獣 | 100〜50m 級 |
| 大型級 | 巨獣の下の階級 |
| 植物級 | 植物のように遷移していく |
| 分階級 ※ | 大型級の死骸を食べて、戦艦級へ届けに行く |

※「分階級」は依頼者の原文の表記。読み方・正確な名称は未確認（「分解級」の可能性もあるため、実装時に依頼者へ確認する）。

## 正体

- 亜光速での飛来、地球の生物への明らかな攻撃の意思、人工物のような形状から、**人類は知的生命体による侵略だと考えていた**。
- 実際には、**滅亡寸前の星から生き残るため**に、全生命の本能的な協力によって母星から射出された地球外生命体で、**知能は無い**。
- 母星では全生命がアンカー種で統一されていた（母星は既に滅亡済み）。
  - 地球のほとんどの生物が炭素生命体で DNA を持つように、アンカー種は「もう少し上の階層まで」同一の種だった。
- 言うなればアンカーは**異星からの避難民・移民**だった。しかし、地球の環境を乗っ取ることを前提としていたため、**侵略という形になった**。

| ゲーム内 | 設定上の階級 | 実装 |

| 甲殻型（旧・蟻型） | 大型級 | `src/enemies/Ant.ts` |
| 跳躍型（旧・蜘蛛型） | 大型級 | `src/enemies/Spider.ts` |
| 飛行型 | （戦艦級が運ぶ／編隊を組む） | `src/enemies/Flyer.ts` |
| 戦艦級（スポーンシップ） | 戦艦級 | `src/enemies/Carrier.ts`（クラス名・データ上の型は互換のため `carrier` のまま） |

| 遠景の巨大な杭 | 国家級 | `src/world/Stake.ts` |

- 戦艦級の挙動（依頼者の指定）:
  - とげとげの周囲の**凹み部分に飛行型がはまっている**。
  - 発進時は**下に少し移動して角から外れ**、**対角線上の同種に当たらないように**移動し、**全員揃って編隊を組む**。
  - 飛行型を離脱させると、**下部と上部で呼吸する（弱点）**。
  - **側面の角から敵を生み出す**。生まれた敵は**丸まっていて、地面に落ちると開いて活動開始**。
- 大型級は死ぬと、虫の死骸のように**体を丸めて**ひっくり返る。
- まだ登場していない階級: 大陸級、母艦級、植物級、分階級。
